# AI Dev Toolkit

A personal collection of GitHub Copilot instructions and AI agent skills.

## Instructions

Custom instructions for GitHub Copilot.

**Locations (IntelliJ IDEA):**

- **Workspace:** `.github/<instruction-file>.md`
- **Global (macOS / Linux):** `~/.config/github-copilot/intellij/<instruction-file>.md`

Use the appropriate filename for each instruction type.

## AI Agent Skills

Reusable skills for GitHub Copilot Agent.

**Locations:**

- **Workspace:** `.github/skills/<skill-name>/SKILL.md`
- **Global:** `~/.copilot/skills/<skill-name>/SKILL.md`
